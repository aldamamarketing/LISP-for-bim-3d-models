## 2024-05-24 - Accessibility Improvements for Property Categories
**Learning:** In purely vanilla web environments embedded in CAD systems (like the TM Digital Inspector), collapsible UI elements often rely on `div` click handlers without native keyboard accessibility. Adding `role="button"`, `tabindex="0"`, `aria-expanded`, keyboard event handlers, and `:focus-visible` styling is essential to make these elements usable for keyboard-only and screen reader users. Furthermore, icon-only buttons require `aria-label`s for context.
**Action:** Always check interactive UI components for native HTML elements (`<button>`, `<input>`). If custom elements are used, manually implement ARIA roles, states, and keyboard event handlers. Ensure all icon-only buttons have descriptive `aria-label`s.
