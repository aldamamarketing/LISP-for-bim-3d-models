## 2024-06-04 - [Accessibility] Icon-only buttons require ARIA labels
**Learning:** Using the `title` attribute for icon-only buttons is insufficient for proper screen reader accessibility. Many icon-only buttons in the LispCentral Dashboard relied solely on visual icons (like Material Symbols) and standard `title` tooltips, which do not reliably convey the button's action to assistive technologies or ensure consistent keyboard focus visibility.
**Action:** When working on UI components, always ensure that icon-only buttons include explicit `aria-label` attributes to define their purpose. Furthermore, apply `:focus-visible` styles (e.g. `focus-visible:ring-2` with the appropriate theme color) so that keyboard navigation users have clear visual feedback of their current position.
