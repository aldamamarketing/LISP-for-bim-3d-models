## 2024-05-15 - [Interactive Card Accessibility]
**Learning:** When creating interactive cards (like resource items) that contain multiple actions (e.g., a main selection action and a secondary 'delete' action), nesting a `<button>` inside an interactive `<div>` with an `onClick` handler causes severe accessibility issues (invalid HTML, confusing screen reader experience, complex event propagation).
**Action:** Replace the interactive `<div>` wrapper with a non-interactive `<div>`. Place an absolutely positioned native `<button>` spanning the full dimensions (`absolute inset-0 z-10 w-full h-full`) to handle the primary action. Place secondary actions (like delete buttons) above it in the z-index stack (`relative z-20`). This ensures clean HTML, proper keyboard navigation, and eliminates the need for `e.stopPropagation()`.
