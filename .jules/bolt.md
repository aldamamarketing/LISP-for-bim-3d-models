## 2024-05-18 - Prevent O(N*M) transformations in Web Palette rendering loops
**Learning:** React components acting as AutoCAD Web Palettes execute inside a restricted/embedded browser control. Rendering loops (like list filtering and grouping) that involve repetitive inner-loop string operations—such as `Array.prototype.filter` invoking `tag.toLowerCase()` on every iteration—can cause noticeable lag.
**Action:** Extract expensive string transformations outside of map/filter/some closures, especially for dynamically generated and frequently rendered list UI. Wrap complex derived state calculations (e.g., list filtering and custom grouping sorts) in `useMemo` hooks so they only run when their base dependencies (`commands` array or `activeFilters`) mutate, skipping re-execution for orthogonal state changes like pinning/unpinning favorites.
