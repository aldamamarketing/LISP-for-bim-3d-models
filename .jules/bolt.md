## 2024-06-09 - Avoid unmemoized string transformations inside loop closures
**Learning:** In React components that render lists with filtering (like `ResourcePalette.jsx`), computing string transformations such as `tag.toLowerCase()` inside a `.filter()` or `.some()` closure causes an O(N * M) performance degradation. Every render will recalculate `.toLowerCase()` on the search tags for every single resource item being tested, unnecessarily stressing the CPU and potentially leading to dropped frames when resource lists grow large.
**Action:** Extract expensive operations like tag normalization (e.g. mapping to lower case) outside the filter loop by computing them once before iterating. Further, always wrap the resulting derived list (like `filteredResources`) in a `useMemo` hook to ensure the filtering logic only executes when its direct dependencies (`resources`, `activeFilters`, `pinnedIds`) change, preventing redundant recalculations on every unrelated render.
