## 2024-05-24 - [Minimize String Allocations in Embedded Browser]\n**Learning:** React components (like LispCommandPalette) run in AutoCAD's embedded HTML5 browser, where JavaScript execution can be significantly slower than standard desktop browsers. O(N*M) string operations (like `toLowerCase()` inside `.some()` closures during list filtering) cause noticeable lag because string allocations are more expensive in this environment.\n**Action:** Always wrap derived lists in `useMemo` and aggressively hoist expensive string transformations (e.g. mapping `activeFilters` to lowercase once) outside of iteration closures to maintain UI responsiveness in the palette.
