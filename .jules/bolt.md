## 2024-06-25 - React Component Render Optimization in HTML5 Palettes
**Learning:** LispCommandPalette acts as the primary web interface within the AutoCAD embedded browser (CEF/Edge). O(N*M) string operations (like repeatedly calling `.toLowerCase()` inside a `.filter()` combined with `.some()`) on large command arrays cause noticeably slow re-renders in this constrained environment when filtering or typing.
**Action:** Always extract invariant string allocations (like mapping active search tags to lower case) outside of inner loop callbacks. Furthermore, use `useMemo` for derived heavy state calculations (like filtering, grouping, and sorting collections) to ensure these expensive operations only re-run when the underlying `commands` or `activeFilters` arrays change, preserving AutoCAD UI responsiveness.
