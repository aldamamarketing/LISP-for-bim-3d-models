Teste Grátis - Instalação Rápida

1. Obter API Key

Insira seu e-mail corporativo para gerar uma chave de teste válida para o MVP e baixar o configurador.

2. Como Usar

  1. Após clicar em gerar, seu navegador baixará o arquivo TMD_Loader.lsp já configurado.
  2. Abra seu AutoCAD.
  3. Arraste o arquivo TMD_Loader.lsp para dentro da janela do AutoCAD. A sincronização ocorrerá automaticamente!
Nota de Segurança do AutoCAD:
Na primeira vez que você arrastar o arquivo, o AutoCAD pode exibir um aviso de segurança perguntando se você confia neste executável. Isso é perfeitamente normal para novos scripts. Clique em "Load" (Carregar) ou "Always Load" (Sempre Carregar) para continuar.

Se você já possui o arquivo loader, não precisa baixar novamente. Apenas abra o arquivo com um bloco de notas e atualize a variável *LISPCENTRAL-KEY* com a nova chave.
