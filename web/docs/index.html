Bem-vindo à Documentação Oficial

A suíte LispCentral (anteriormente TMD) revoluciona a automação no AutoCAD transformando-o num verdadeiro software BIM/3D paramétrico para estruturas metálicas.

O Novo Paradigma (V5)

Nesta versão 5.0, abandonamos as "linhas base" e polilinhas construtivas. Agora cada sólido 3D (3DSOLID) contém o seu próprio ADN embutido internamente via LDATA.

Vantagens do Novo Sistema

  • Edição Direta: Você pode esticar a viga usando os Grips nativos do AutoCAD e os metadados se adaptam automaticamente.
  • Nuvem: Os comandos (como LC_JOINTS ou LC_BUILD) não instalam arquivos `.fas` ou `.vlx` no seu HD, eles rodam injetados diretamente na RAM.

Navegação
