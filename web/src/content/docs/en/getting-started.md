---
title: 'Getting Started'
description: 'How to install the LispCentral Loader in AutoCAD and connect your account for the first time.'
icon: "rocket_launch"
---LispCentral does not require heavy file installations. Everything works via a small LISP script called the Loader.

1. Log in to the Client Portal.
2. Navigate to the Licenses & Access tab.
3. Scroll to 'Your Access Key' and click Download.
4. In AutoCAD, type the APPLOAD command.
5. Select the downloaded file and click Load.
6. To load automatically when opening AutoCAD, add it to the Startup Suite in the same APPLOAD window.
